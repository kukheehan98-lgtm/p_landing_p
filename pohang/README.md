# 배움알림 포항 — 지역 무료 강연 큐레이션 MVP

> 좋은 강연은 늘 있었습니다. 몰라서 못 갔을 뿐입니다.

포항의 무료 강연·강좌를 한 곳에 모으고, 신청 마감 전에 알림을 보내주는 서비스의
**수요 검증용 MVP**입니다. 크롤링·API·백엔드가 없는 이른바 *오즈의 마법사 MVP* 구조로,
뒷단은 사람이 처리하고 앞단만 진짜처럼 동작합니다.

## 이 MVP가 검증하려는 것

| 질문 | 측정 지표 | 확인 위치 |
| --- | --- | --- |
| 알림을 받고 싶어 하는 사람이 있는가 | 알림 신청 수 / 방문자 수 | `?admin=1` 패널 |
| 어떤 테마에 수요가 몰리는가 | 테마별 신청자 분포 | `?admin=1` 패널 |
| 정보만 봐도 실제 행동으로 이어지는가 | 「신청 페이지 열기」 클릭 수 | `?admin=1` 패널 |
| 주최 측이 모객 대행에 관심이 있는가 | 기관 제휴 문의 수 | `?admin=1` 패널 |

**판단 기준(예시)** — 방문 100명 기준 알림 신청 전환율이 10%를 넘으면 다음 단계(카카오 알림톡 자동화)로,
3% 미만이면 문제 정의부터 다시 봅니다.

## 파일 구성

```
pohang/
├── index.html        # 랜딩 + 강연 목록 + 신청 폼 + 운영자 패널 (단일 파일)
├── data.js           # ★ 큐레이션 데이터 — 운영자가 매주 갈아끼우는 유일한 파일
├── data-template.csv # Google Sheets 로 관리할 때 쓰는 컬럼 템플릿
└── README.md
```

## 로컬에서 보기

저장소 루트에서 정적 서버를 띄운 뒤 `/pohang/` 으로 접속합니다.

```bash
pwsh -File serve.ps1
```

- 서비스 화면 → `http://localhost:5173/pohang/`
- 운영자 패널 → `http://localhost:5173/pohang/?admin=1`

## 주간 운영 루틴 (약 40분)

1. **수집** — 아래 기관의 신규 공지를 훑습니다.
   포항시립도서관(포은중앙·영암·오천·대잠) / 포항시평생학습원 / 포항문화재단 /
   포항시보건소 / 포항창업지원센터
2. **선별** — 참가비 0원, 개인 신청 가능, 마감 전인 건만 남깁니다.
3. **요약** — 공지문을 AI에 넣고 아래 프롬프트로 3줄을 뽑습니다.

   > 다음 공지문을 3줄로 줄여줘. 각 줄은 (1) 누구에게 맞는지 (2) 무엇을 하는지
   > (3) 준비물·유의사항 순서로. 홍보 문구는 빼고 사실만. 한 줄 40자 이내.

4. **입력** — `data.js` 의 `LECTURES` 배열을 갱신하고 저장합니다.
5. **발송** — `?admin=1` 에서 CSV를 복사해, 테마가 맞는 신청자에게 문자를 **수동으로** 보냅니다.
   (100명 미만까지는 수작업이 자동화보다 빠릅니다.)

## 실데이터로 전환하기

`data.js` 상단의 세 상수만 바꾸면 됩니다.

```js
const IS_SAMPLE_DATA  = false;   // 상단 샘플 안내 배너를 끕니다
const SUBMIT_ENDPOINT = '';      // Formspree / Make.com Webhook URL 을 넣으면 실제 전송
const SIGNUP_BASELINE = 0;       // 표시용 기준값. 0 이면 순수 실측치만 노출
```

> ⚠️ 현재 `data.js` 의 강연 12건은 **구조 확인용 샘플**입니다.
> 실제 모집 정보가 아니므로, 배포 전 반드시 실제 공지 데이터로 교체하세요.
> 교체 전까지는 페이지 상단에 샘플 안내 배너가 표시됩니다.

## 아직 연결되지 않은 것

- **카카오 알림톡** — 발송은 현재 수작업입니다. 신청자 100명을 넘기면 알림톡 API로 전환합니다.
- **신청 데이터 보관** — `SUBMIT_ENDPOINT` 가 비어 있으면 브라우저 `localStorage` 에만 남습니다.
  실제 모집 전에 반드시 외부 엔드포인트를 연결하세요. (브라우저를 지우면 데이터도 사라집니다.)
- **크롤링** — 자동 수집은 수요가 확인된 뒤에 붙입니다. MVP 단계에서는 사람이 더 빠르고 정확합니다.
