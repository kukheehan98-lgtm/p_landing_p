## 추가 — 시험 배너 깜빡임 (19a5eed, 09-13 15:51 배포)

운영 화면 맨 위에 「기능 연결 테스트 · 모의 저장 / 실제 문자 발송 없음」이 보인다는
제보. 배너는 HTML 에 보이는 채로 들어가고 prepareUI() 가 나중에 숨기는 구조였는데,
메모리가 부족한 기기에서는 그 틈이 읽힐 만큼 길어졌다.

순서를 뒤집었다. 배너는 `hidden` 으로 시작하고 `if(!production)` 가지에서만 꺼낸다.
운영 주소에서는 그 줄이 실행되지 않으므로 기기가 아무리 느려도 나타날 수 없다 —
빠른 쪽이 이기기를 기대하는 경주가 아니라 구조적 보장이다.
통합시험 하네스(culturepick-integration)는 release-runtime.js 를 쓰지 않으므로
건드리지 않았다. 그 페이지는 항상 시험이라 경고가 계속 보여야 한다.

**측정 방법에 대한 교훈** — 처음에 `el.hidden` 만 읽고 "안 보인다"고 판단했다.
그건 표시가 붙었는지일 뿐 화면에 보이는지가 아니다. CSS 가 display 를 지정했다면
`hidden` 은 무시된다. 이후 `getComputedStyle().display` 와 실제 높이로 다시 쟀다.
플래그가 아니라 결과를 재야 한다.
